## 🔄 ACTUALIZACIONES Y MANTENIMIENTO

### Cuando cambies precios
Editar en estos 4 sitios:
1. `index.html` (sección pricing)
2. `GHL-2-BODY-HTML.html` (misma sección)
3. `PROMPTS-RETELL-AGENTES.md` (cuerpo del prompt)
4. `PORTFOLIO-TECNICO-ARES.md` (tabla de planes)

Y volver a pegar los bloques GHL.

### Cuando añadas un nuevo producto
1. Añadirlo a `PORTFOLIO-TECNICO-ARES.md` (sección 3)
2. Construirlo siguiendo `IMPLEMENTACION-TECNICA-DETALLADA.md`
3. Añadirlo al sitio web (nueva sección)
4. Mencionarlo en los prompts del agente

### Cuando añadas un nuevo idioma
1. Añadir traducciones en el JS de i18n del sitio
2. Crear First Message en ese idioma para el agente
3. Configurar voz en Retell con accent del idioma

### Cuando añadas una nueva industria
1. Añadir prompt nuevo a `PROMPTS-POR-INDUSTRIA.md`
2. Añadir testimonio a la sección de testimonios del sitio
3. Crear case study si tienes resultados reales
